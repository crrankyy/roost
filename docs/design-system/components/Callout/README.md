# Callout

One aside the reader shouldn't miss: a note, a warning, a recorded decision, a success or a danger.

**Use** `.lr-callout` with a 16px Lucide icon (`svg.lr-icon`) then a `p`, or a block whose first `strong` is a short heading. `data-tone`: none (note, blue), `warning` (peach), `decision` (accent), `success` (green), `danger` (red).

**Look** — `radius-2xl`, `space-4` padding, 7% tint and 25% edge of the tone; the icon takes the tone; text 14/20 `foreground`.

- Do keep a callout to one or two sentences.
- Don't stack callouts; one per section at most.
