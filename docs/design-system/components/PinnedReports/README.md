# PinnedReports

The reports I keep returning to (a runbook, a key decision), in one row under the triage strip. Shown only when something is pinned.

**Use** `.hub-sec` with a "Pinned" head, then `.hub-pins` holding `a.lr-panel.hub-pin` items: a pin icon in `agent`, then `.hub-pin-text` with `.hub-pin-title` and a `.hub-meta` line (KindBadge, project › stream). Pins come from KV in the order they were pinned.

**Look** — `radius-xl` chips up to 320px wide, titles cut with an ellipsis; the row scrolls sideways on phones with its scrollbar hidden.

- Do pin from the report's pill; there is no pin control in lists.
