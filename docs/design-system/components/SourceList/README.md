# SourceList

The sources a report drew on, grouped under short headings, ending every report that cites anything. With it, the report footer.

**Use** `.lr-panel.lr-card.lr-sources` with `h3` group headings and `ul` lists of links; related links can share a line with ` · `. Close the report with `p.lr-footer` (or `footer.lr-footer`) for caveats about the sources.

**Look** — one column on phones, two from 1000px; groups never split across columns; links 14/20 in `agent`.

- Do link the exact page used, not a homepage.
- Don't list sources the report didn't use.
