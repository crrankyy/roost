# Timeline

Dated events in order: an incident from alert to resolution, or the history of a stream.

**Use** `ol.lr-timeline` of `li.lr-event`, each holding a block with `.lr-event-time`, an `h3` and a `p`. `data-tone` colours the event's dot: `red` (impact starts), `peach` (finding), `green` (resolved), `accent` (decision); none is neutral.

**Look** — a 10px dot with a soft halo in its tone, joined by a hairline; time in meta size, tabular figures.

- Do give times in one zone and say which on the first event.
- Don't colour every event; keep tone for the turning points.
