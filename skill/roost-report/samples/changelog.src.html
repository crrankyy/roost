Key findings
  1. v1.0.0 and v1.1.0 are one build. Both tags point at 639a26a, made in the same second, because the five features cut to v1.1 were finished before anything was tagged (v1.1.0).
  2. v1.0.0 delivered the M-05 set and the v0.3/v0.6 leftovers. Export, citations, Tier 2 diagrams, MCP, multiplayer and plugins landed with 11 features v0.4.0 had left open (v1.0.0).
  3. The v1 build missed three performance budgets. Cold start, 100 MB open and memory are open high-severity bugs, and the binary is 138 MB against 80 MB (v1.0.0).
  4. A whole milestone is done but untagged. 12 M-07 features merged between 2 and 4 November, including Reader as the default view (Unreleased).
  5. The Azimuth record and git disagree on details. Milestones name d69785f, 1 November and no tag; git says 639a26a, 2 November, v1.0.0 and v1.1.0 (Tags and the record).
Unreleased

Twelve visual-style features are done on main but carry no tag

Since v1.1.0, main has 105 commits from 2 to 4 November, with 13,049 lines added under crates/. They finish every feature in M-07 (v1.2, still active); M-08 (v1.3) holds four ideas.

4 NovF-084, F-089 closed

Reader matches the mockups. The last F-089 fixes make Reader's caches rebuild after the first parse, draw bold at its weight and scaled spans at their size, use mono for Reader code and drop spelling squiggles in Reader (aba7754, 0f0add1). Both features closed in 5471705.

3 NovF-084, F-089 built

Notes open in Reader. As ADR-0017 decides, an existing note opens in Reader and a new note, daily note or the scratchpad in Source; Live Preview moves behind ⌘ ⌥ P and the new Toggle live preview and Toggle source mode commands. F-089 adds Reader headings, chips, tags, task boxes, callout headers, ruled tables, a front-matter breadcrumb and the centred title band.

3 NovF-074 to F-083

The theme drives every surface. Ten features specced and built in one day: design tokens, theme-driven window chrome, one overlay for the palette and switcher, tabs in the title band with a mode toggle, one panel style, rich-block styling, Reader typography, motion and focus rings, notice cards out of the window title, and per-block font sizes in the display map.

2 NovAfter the tag

The manifest catches up. 77ae783 sets the workspace version to 1.1.0, so zmd --version stops printing 0.4.0. M-07 was created the same day from a screenshot set.

Source: git log v1.1.0..main; feature summaries from .azimuth/features/F-074 to F-089; ADR-0017.

Known issues

F-072's measurements on the v1 build left three budgets missed and open as high-severity bugs: cold start about 700 ms against 200 ms (BUG-0012), first paint of a 100 MB file about 4.8 s against 500 ms (BUG-0013), and 460–620 MB resident memory against 400 MB (BUG-0014). BUG-0015, glyph corruption once a second window opens, is also open, and the release binary is 138 MB against the 80 MB budget.

Source: .azimuth/issues/BUG-0012 to BUG-0015; binary size from the handoff in SES-20261031-1836.

v0.4.0 · 24 October 2026

v0.4.0 was the first tagged release: the source editor, live preview and the core of the PKM layer

A native Rust Markdown editor for macOS on iced, wgpu and cosmic-text. It was versioned 0.4 because the build was past the v0.3 feature set and short of v0.6.

MilestoneDonePlannedStatus at v0.4.0
M-01 Phase 0 spike66Complete
M-02 v0.1 core text engine and source mode1818Complete
M-03 v0.3 hybrid live preview and rich blocks1722Partial
M-04 v0.6 PKM graph, search and writing craft915Partial
Total5061

Source: the v0.4.0 annotated tag message (git cat-file -p v0.4.0).

  • Text engine. Rope buffer with an EditTransaction bus, undo/redo tree, write-ahead log and anchors (ADR-007); large-file modes (ADR-008).
  • Source mode. GPU editor with tree-sitter highlighting, 20 bundled code grammars, Vim/Helix modal editing, multi-cursor and IME.
  • Live preview. Inline unfold, editable tables, native math through typst, svgbob and pikchr diagrams, smart clipboard and split preview.
  • PKM core. SQLite FTS5 and petgraph index, wikilinks with refactoring on rename, backlinks, fuzzy switcher and workspace search.
  • Fixed. A SIGSEGV about two minutes after launch on Touch Bar Macs (BUG-0005, critical): the accesskit adapter now attaches before the window shows.
  • Size. Stripped release binary 70.8 MB against the 80 MB budget.

Source: the v0.4.0 tag message, condensed; .azimuth/issues/BUG-0005.
